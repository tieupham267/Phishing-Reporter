**Implementation approach:**

The "Office" key currently has one child key: `_9E3D88F87A8C437E9BFCA027C7308223` (Outlook). Add a second child key for "16.0" alongside it.

Inside the existing "Office" key's "Keys" block (which currently contains the "Outlook" key), add a new sibling key hierarchy:

```
"{60EA8692-D2D5-43EB-80DC-7906BF13D6EF}:_NEW_GUID_16_0"
{
"Name" = "8:16.0"
"Condition" = "8:"
"AlwaysCreate" = "11:FALSE"
"DeleteAtUninstall" = "11:FALSE"
"Transitive" = "11:FALSE"
    "Keys"
    {
        "{60EA8692-D2D5-43EB-80DC-7906BF13D6EF}:_NEW_GUID_OUTLOOK"
        {
        "Name" = "8:Outlook"
        ...
            "Keys"
            {
                "{60EA8692-D2D5-43EB-80DC-7906BF13D6EF}:_NEW_GUID_RESILIENCY"
                {
                "Name" = "8:Resiliency"
                ...
                    "Keys"
                    {
                        "{60EA8692-D2D5-43EB-80DC-7906BF13D6EF}:_NEW_GUID_DONOTDISABLE"
                        {
                        "Name" = "8:DoNotDisableAddinList"
                        ...
                            "Keys" {}
                            "Values"
                            {
                                "{ADCFDA98-8FDD-45E4-90BC-E3D20B029870}:_NEW_GUID_VALUE"
                                {
                                "Name" = "8:ZeroD.PhishReporter"
                                "Condition" = "8:"
                                "Transitive" = "11:FALSE"

                                "Value" = "3:1"
                                }
                            }
                        }
                    }
                }
            }
        }
    }
    "Values" {}
}
```

**CRITICAL details:**
- Generate new unique GUIDs for each `_NEW_GUID_*` placeholder. Use uppercase hex format like the existing keys (e.g., `_A1B2C3D4E5F6789012345678ABCDEF01`). You can generate them using `python -c "import uuid; print(uuid.uuid4().hex.upper())"` or use deterministic unique strings.
- The DWORD value for `ZeroD.PhishReporter` uses `"ValueTypes" = "3:3"` (DWORD type) and `"Value" = "3:1"` (value 1).
- The value name MUST be exactly `ZeroD.PhishReporter` — this is the ProgID that matches the existing registration under `Addins`.
- Use HKPU (per-user hive), NOT HKCU — the `.vdproj` uses HKPU for per-user registry keys that follow the user profile.
- Match the existing indentation and formatting style exactly.
- The new hierarchy is added INSIDE the existing "Office" key's "Keys" block, as a sibling to the existing "Outlook" key.

**Do NOT:**
- Modify any existing registry keys or values
- Change the existing Addins\ZeroD.PhishReporter entries
- Use HKLM or HKCR — this must be per-user
