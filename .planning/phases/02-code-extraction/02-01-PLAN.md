<task type="auto">
  <name>Task 1: Wrap ribbon callbacks in exception-safe try/catch and fix Settings persistence</name>
  <files>PhishingReporter/Ribbon.cs</files>
  <action>
Wrap all four public ribbon callback methods in Ribbon.cs with top-level try/catch blocks to prevent unhandled exceptions from crossing the COM boundary and triggering Outlook's soft-disable mechanism (STRT-05). Also add Settings.Save() calls after counter increments (BUGF-02).

**Exception-safe wrappers (STRT-05):**

1. `reportPhishing(Office.IRibbonControl control)` -- wrap the entire existing body (including the MessageBox confirmation and call to reportPhishingEmailToSecurityTeam) in try/catch(Exception ex). In the catch: Logger.Error(ex, "Unhandled exception in reportPhishing callback"), then show a MessageBox wrapped in its own inner try/catch (since even MessageBox can fail in degraded COM states). The inner catch must swallow silently.

2. `getGroup1Image(IRibbonControl control)` -- wrap `return Resources.phishing;` in try/catch. In catch: Logger.Error(ex, "Unhandled exception in getGroup1Image callback"), return null (Outlook handles null gracefully by showing no image).

3. `GetCustomUI(string ribbonID)` -- wrap `return GetResourceText(...)` in try/catch. In catch: Logger.Error(ex, "Unhandled exception in GetCustomUI callback"), return null.

4. `Ribbon_Load(Office.IRibbonUI ribbonUI)` -- wrap `this.ribbon = ribbonUI;` in try/catch. In catch: Logger.Error(ex, "Unhandled exception in Ribbon_Load callback").

**CRITICAL anti-pattern:** Do NOT catch and re-throw. The try/catch at the callback boundary must be the terminal handler. Re-throwing defeats the purpose.

**Settings persistence (BUGF-02):**

5. After line 159 (`Properties.Settings.Default.gophish_reports_counter++;`), add: `Properties.Settings.Default.Save();`

6. After line 168 (`Properties.Settings.Default.suspecious_reports_counter++;`), add: `Properties.Settings.Default.Save();`

Do NOT call Save() multiple times in the same code path. Each counter branch gets exactly one Save() call after its increment.

/// <summary>
/// Result of GoPhish campaign detection and reporting.
/// Replaces magic strings "OK", "ERROR", and "NaN".

internal enum GoPhishResult

    /// <summary>No GoPhish header found in email -- not a simulated campaign.</summary>
    NotFound,

    /// <summary>GoPhish campaign detected and successfully reported to server.</summary>
    Reported,

}
