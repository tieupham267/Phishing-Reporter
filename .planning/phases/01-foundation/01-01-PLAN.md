Perform two independent but related changes in the project files:

**1. .NET Framework 4.8 Retarget (INFR-01):**

In `PhishingReporter/PhishingReporter.csproj`:
- Change `<TargetFrameworkVersion>v4.6.1</TargetFrameworkVersion>` to `<TargetFrameworkVersion>v4.8</TargetFrameworkVersion>`
- Replace the `.NETFramework,Version=v4.6.1` BootstrapperPackage block (lines 49-53) with:
  ```xml
  <BootstrapperPackage Include=".NETFramework,Version=v4.8">
    <Visible>False</Visible>
    <ProductName>Microsoft .NET Framework 4.8 %28x86 and x64%29</ProductName>
    <Install>false</Install>
  </BootstrapperPackage>
  ```
  Note: `Install=false` because .NET 4.8 is pre-installed on all target machines (Windows 10 1903+ / Windows 11). No need to bundle the redistributable.

**2. HtmlAgilityPack Update (INFR-04):**

In `PhishingReporter/PhishingReporter.csproj`:
- Update the HtmlAgilityPack Reference from `Version=1.11.23.0` to `Version=1.12.4.0`
- Update the HintPath from `..\packages\HtmlAgilityPack.1.11.23\lib\Net45\HtmlAgilityPack.dll` to `..\packages\HtmlAgilityPack.1.12.4\lib\Net45\HtmlAgilityPack.dll`

In `PhishingReporter/packages.config`:
- Change `<package id="HtmlAgilityPack" version="1.11.23" targetFramework="net461" />` to `<package id="HtmlAgilityPack" version="1.12.4" targetFramework="net48" />`

After editing files, run NuGet restore to download the new HtmlAgilityPack package:
```bash
cd PhishingReporter && nuget restore packages.config -PackagesDirectory ../packages
```
If `nuget` CLI is not available, use:
```bash
dotnet restore PhishingReporter.csproj
```
Or download directly — the critical part is that `packages/HtmlAgilityPack.1.12.4/` directory exists with the DLL.
